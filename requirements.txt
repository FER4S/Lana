# ─────────────────────────────────────────────
#  Lana – Voice AI Assistant
#  requirements.txt — shared core, needed everywhere
#
#  Speech dependencies are NOT here. They differ per deployment and are large:
#
#    requirements-local.txt  – Windows workstation, GPU. faster-whisper +
#                              Kokoro + openWakeWord, microphone on the machine.
#                              Needs the CUDA build of torch installed FIRST;
#                              see README.
#    requirements-server.txt – Linux host, no GPU, no sound card. Speech runs
#                              through hosted APIs with the microphone in a
#                              browser tab.
#
#  Install this file plus exactly one of those. Installing the local set on the
#  server would pull ~2.5 GB of CUDA wheels that cannot be used, and bind
#  PortAudio on a box with no audio devices.
# ─────────────────────────────────────────────
